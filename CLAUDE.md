# Multi-Project-Playground

Several unrelated projects share this repo; each has its own folder and,
usually, its own development branch. Read the project's own `CLAUDE.md`
before working on it:

- `rain-world-desktop/`: **moved** to its own repo,
  <https://github.com/NicksSoftwareFun/Rain-World-Desktop> (GitHub Pages:
  <https://nickssoftwarefun.github.io/Rain-World-Desktop/>). The copy here is
  frozen; don't develop it further.
- `weather-radar-viewer/`: SKYWATCH radar PWA and Android app. It owns this
  repo's GitHub Pages site and the workflows in `.github/workflows/`
  (deployed from the repo's default branch).
